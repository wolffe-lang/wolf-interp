R-is81-4: the private helper design was rejected and not implemented. All Unix spawn paths now check executable access before reading the first four bytes. Missing/non-executable candidates are left to std spawn for ENOENT/EACCES. Shebang, ELF, listed Mach-O endiannesses and fat Mach-O prefixes are admitted; executable unknown formats return io/ENOEXEC8 before libc can retry under a shell.

Limitation by design: a Linux binfmt_misc-registered format with another prefix is refused even if that kernel would run it. No registry change or privileged binfmt test was performed. The prefix guard is not an ELF/Mach-O validator; recognized formats remain the platform loader decision. No new dependency, feature, unsafe block, helper process, command or embedding prerequisite was added.
